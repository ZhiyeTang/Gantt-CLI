# 02: 放行无关本地文件，并在清理前自动保全

**What to build:** 开始任务时记录文件来源，结合 Agent 显式分类区分本地文件和任务产物。无关本地文件不阻塞合并；清理前自动保存已分类的配置与非交付内容，未分类新文件交给 Agent 处理后重试。

**Blocked by:** None (can start immediately).

**Status:** done

**Spec:** [按任务需要选择执行流程](../../../docs/specs/adaptive-task-workflow.md)

- [x] 起始文件记录与显式分类持久化到现有记录体系；不靠文件名判断归属，不把“原本存在”视为允许删除。
- [x] 无关本地文件允许留在目标目录，实际可能被覆盖的文件仍得到保护；提交范围检查保持有效。
- [x] 已分类本地配置和非交付内容保存到 worktree 外按 Assignment 区分的目录，保持相对路径并输出保存位置，不输出配置正文。
- [x] 保全同时覆盖未跟踪和 ignored 文件；不得将 ignored 状态直接等同于可丢弃。
- [x] 保存成功并核对完整后才移除现场。保存失败、已有目标内容冲突或执行中断时不丢失原件；重试不能覆盖其他内容或不断复制重复保存目录。
- [x] 未分类新文件和未提交的跟踪文件修改返回明确路径及处置提示，保留现场；应提交的新源码不能仅靠文件保存绕过交付。
- [x] 普通清理、中断任务丢弃及创建失败回滚使用一致的删除保护，子模块修改和含独有 Git 数据的嵌套仓库继续得到保护。
- [x] CLI 集成测试覆盖无关配置合并、覆盖冲突、ignored 配置保全、保存失败与重试，以及现有子模块和嵌套仓库保护。
